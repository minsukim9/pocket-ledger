# 왜 CSV인가? JSONL 및 SQLite와 비교

[← 프로젝트 소개](../README.md) · [저장 형식](storage.md) · [아키텍처](architecture.md)

이 프로젝트는 **내부 저장은 CSV**, 외부 교환도 CSV를 사용합니다. 비교 대상 JSON은 한 문서로 저장하는 일반 JSON(`[...]`)과 **한 줄당 한 객체인 JSONL**을 구분해야 합니다. 미션의 스트리밍 요구를 만족시키는 비교 대상은 주로 JSONL입니다.

| 관점 | CSV (현재 선택) | JSONL | 일반 JSON 배열 |
| --- | --- | --- | --- |
| 순차 읽기 | `csv.DictReader`로 행 단위 | 각 줄 `json.loads()`로 읽기 | 보통 `json.load()`로 전체 문서 읽기 |
| 데이터 구조 | 열이 정해진 평면 거래에 유리 | 선택 필드·중첩 구조 표현에 유리 | 중첩 구조에 유리 |
| 데이터 타입 | 파일 안에서는 문자열; 검증/변환 필요 | 숫자/불리언/리스트 등을 표현 | JSONL과 동일 |
| 도구 호환 | 스프레드시트·SQL import·ETL에서 흔함 | 로그·문서 처리 도구와 친화적 | API·설정 파일과 친화적 |
| 변경 비용 | 열 추가 시 헤더와 기존 데이터 처리 정책 필요 | 신규 속성 추가 비교적 유연 | 구조는 유연하나 통째로 재작성하기 쉬움 |
| 주의 사항 | 쉼표·개행·따옴표 인용, 태그 목록 규칙 | 레코드별 스키마 불일치 관리 | 큰 파일에 스트리밍 파서 별도 필요 |

**CSV를 선택한 이유:** 거래·카테고리·예산이 표로 표현하기 쉽고, 과제에서 CSV import/export를 이미 요구합니다. 파일을 사람이 열어보거나 다른 도구로 넘기기도 쉽습니다. 다만 CSV가 데이터 안전성을 자동으로 제공하지는 않습니다. 헤더 검증, 날짜/정수 변환, 임시 파일 교체, 대량 파일의 재작성 정책을 코드에서 구현했습니다.

**언제 JSONL이 나은가:** 거래마다 다른 추가 속성, 중첩 영수증 항목, 복잡한 태그/메타데이터가 중요해질 때입니다. JSONL 역시 제너레이터로 스트리밍할 수 있으므로 "JSON은 스트리밍 불가"가 아닙니다. 반대로 JSONL도 갱신·삭제 시 파일 재작성이나 별도 저장 구조가 필요합니다.

## SQLite로 이전한다면

Python 표준 라이브러리의 `sqlite3`를 사용할 수 있습니다. CSV는 표 형태라 **행 → 레코드, 헤더 → 열**로 매핑하기 편하지만, DB로 바뀐다고 자동으로 마이그레이션이 끝나는 것은 아닙니다. JSONL도 변환 스크립트를 작성하면 이전할 수 있습니다.

1. `transactions`, `categories`, `budgets`, `recurrences` 테이블과 기본 키·유형/금액 제약을 설계합니다. 태그는 필요에 따라 별도 `transaction_tags` 테이블로 분리합니다.
2. 현재 검증 함수로 CSV를 확인하면서 `sqlite3` 트랜잭션 안에서 가져오고, 실패한 행을 보고합니다.
3. `TransactionStore` 등의 파일 I/O를 DB 저장소로 대체하고 서비스/CLI는 가능한 한 유지합니다. `list/search/summary`는 SQL 필터·정렬·집계와 인덱스로 옮길 수 있습니다.
4. DB 스키마 버전, 기존 CSV 백업, 마이그레이션 후 건수/합계 대조, 백업·복구 절차를 준비합니다. 기존 ID를 보존할지 새 키를 발급할지도 정해야 합니다.

**SQLite로 얻는 것:** 기본 키/제약 조건, 다중 테이블 트랜잭션, 인덱스에 기반한 검색, 파일 전면 재작성 감소, 파일 간 일관성 확보. **추가로 필요한 것:** 스키마 마이그레이션, DB 백업/복구 설계, 동시 접근을 고려한 트랜잭션·잠금 처리. 다중 프로세스를 지원하려면 단순히 확장자를 `.db`로 바꾸는 것만으로는 부족합니다.

결론적으로 **"CSV가 DB 이행에 항상 더 우수하다"가 아니라**, 현재처럼 평면 테이블 구조의 소규모 프로그램에서 변환 경로가 단순한 편입니다. 데이터 규모와 동시 수정 요구가 커지면 파일 형식 자체보다 저장소·트랜잭션 설계의 중요성이 커집니다.
